觀察步驟What to watch

1. 按頁首（或左欄）重置。確認：未選氣體、overlay 提示「請先選擇氣體」、觀察紀錄清空、語言不變。確認本檔是 science 的 gas-test（氣體鑑定：H₂／O₂／CO₂／N₂），不是 sibling gas-tests，也不是 flame-test（焰色試驗）。然後在左欄點選一種氣體，看試管標記與 status。

1. Press header (or side) Reset. Confirm: no gas selected, overlay asks you to choose a gas, log cleared, language unchanged. This file is science gas-test (H₂／O₂／CO₂／N₂), not sibling gas-tests, and not flame-test. Then select a gas on the left and note the tube mark and status.

2. 選 H₂，再選燃燒中的木條。觀察木條降至試管口附近、發出「啵」、舞台輕微震動，並讀右欄觀察與方程式 2H₂ + O₂ → 2H₂O。

2. Select H₂, then burning splint. Watch the splint approach the tube mouth, hear／see the pop, a slight shake, and the log equation 2H₂ + O₂ → 2H₂O.

3. 選 O₂，再選帶有餘燼的木條。觀察餘燼重新燃燒（重燃）。可對照：同用餘燼測 H₂／CO₂／N₂ 時餘燼熄滅。

3. Select O₂, then glowing splint. Watch the ember relight. Contrast: glowing splint goes out for H₂／CO₂／N₂.

4. 選 CO₂，先用石灰水——液體變乳白色；再用碳酸氫鹽指示劑——由紅變黃。對照 H₂／O₂／N₂：石灰水保持清澈、指示劑保持紅。

4. Select CO₂. With limewater, the liquid turns milky; with bicarbonate indicator, red → yellow. For H₂／O₂／N₂, limewater stays clear and the indicator stays red.

5. 選 N₂，試燃燒／餘燼（熄滅）與石灰水／指示劑（無明顯變化）。可選做「未知氣體挑戰」（加分，不是五題課堂問題）。再按重置：回未選氣、清 log、語言不變。打開原理解說與課堂問題——主軸是 氣體鑑定／木條／石灰水／指示劑，不是焰色試驗。

5. Select N₂ and check extinguishing／no change. Optionally try the unknown-gas challenge (bonus—not the five-question quiz). Reset: no gas, clear log, language unchanged. Open Principles／Quiz—focus is gas ID／splints／limewater／indicator, not flame tests.

原理解說Principles

概念

Concept

氣體鑑定是初中綜合科學常用的定性方法：用燃燒／餘燼木條、石灰水、酸鹼指示劑等標準測試，依現象辨識常見氣體。本模擬（slug gas-test）讓學生對 H₂／O₂／CO₂／N₂ 做可控對照實驗，並把觀察寫進紀錄。

Gas tests are a junior-science qualitative toolkit: burning／glowing splints, limewater, and acid–base indicators help identify common gases. This sim (slug gas-test) lets students compare H₂／O₂／CO₂／N₂ and log observations.

機制／流程

Mechanism／workflow

1. 氫氣 (H₂)：極易燃；燃燒木條在試管口點燃 H₂–空氣混合物 →「啵」聲。示意：2H₂ + O₂ → 2H₂O。
2. 氧氣 (O₂)：強烈助燃；餘燼木條可重燃；燃燒木條火焰更旺。
3. 二氧化碳 (CO₂)：與石灰水反應生成不溶碳酸鈣 → 變乳白：CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O；溶於水呈微酸，指示劑紅→黃：CO₂ + H₂O ⇌ H₂CO₃；不助燃。
4. 氮氣 (N₂)：不活潑——不助燃、不可燃；對石灰水／指示劑通常無明顯變化（對照組）。
5. 策略：先觀察、再對照表；未知氣體須多測再判斷。
6. 範圍：課堂示意四種氣體；不做焰色試驗（見 flame-test）；不與 sibling gas-tests 混檔；本檔不含 Cl₂／NH₃／SO₂ 等擴展氣體表。

1. Hydrogen (H₂): flammable; burning splint at the mouth → “pop”. Sketch: 2H₂ + O₂ → 2H₂O.
2. Oxygen (O₂): strongly supports combustion; glowing splint relights; burning flame grows.
3. Carbon dioxide (CO₂): limewater → milky CaCO₃: CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O; mildly acidic in water, indicator red → yellow: CO₂ + H₂O ⇌ H₂CO₃; does not support combustion.
4. Nitrogen (N₂): unreactive control—extinguishes flames; little／no change with limewater／indicator.
5. Strategy: observe first, then use the summary table; for unknowns, test before guessing.
6. Scope: four classroom gases—not flame tests (flame-test); not the sibling gas-tests file; no Cl₂／NH₃／SO₂ table in this slug.

日常／課堂例子

Everyday／class example

呼出的氣體使石灰水變混濁，是因為含較多 CO₂——與實驗室石灰水測試同一原理。蠟燭在密閉容器熄滅，常與氧氣耗盡、二氧化碳累積有關（課堂層次示意）。

Exhaled air turns limewater cloudy because of extra CO₂—the same idea as the lab limewater test. A candle in a closed jar goes out as oxygen falls and CO₂ rises (classroom-level picture).
