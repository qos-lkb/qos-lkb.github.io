原理解說

本模擬運用 Speech Synthesis API 即時發音，並以 Web Audio API AnalyserNode 繪製波形。

可選美式／英式口音及男聲／女聲。詞彙模式按學科課題篩選；自訂模式輸入後可全篇或逐詞朗讀。

涵蓋生物、化學、物理與實驗室常用科學術語，方便練習英文發音。

提示：首次播放需使用者點擊；若無聲音請確認系統音量及英文語音包。

觀察步驟

  1. 選模式：「學科詞彙篩選」或「自訂文字朗讀」；設定口音、男／女聲、語速與音量。
  2. 詞彙模式：左欄選課題，右方點卡片聆聽發音。
  3. 自訂模式：輸入英文後按「完成輸入」，文字變成可點選詞語。
  4. 閱讀模式可「全篇閱讀」或單擊逐詞朗讀；雙擊返回編輯。
