# Science Simulations — 潛在模擬程式規劃（300 項）

> **用途**：規劃以互動模擬／小型 web app 輔助課堂、自學或探究活動。  
> **結構**：學科 → **課題分類** → 具體構想（每項可獨立成頁，或銜接現有 `physics/`、`chem/`、`biology/`、`science/`、`astronomy/`、`geography/`、`other/` 資源）。  
> **對照**：製作前先搜尋儲存庫是否已有類似模擬，避免重複造輪；延伸／科普深度項目宜標註難度。

## 使用建議

### 優先順序

1. **對照課綱**：HKDSE／初中科學各單元學習重點。  
2. **對照現有資源**：先搜尋 `physics/`、`chem/`、`biology/`、`science/`、`astronomy/`、`geography/`、`other/` 及資料庫已發佈模擬。
