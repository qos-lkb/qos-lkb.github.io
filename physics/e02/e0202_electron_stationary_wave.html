德布羅意駐波與角動量量子化

Bohr model & standing matter waves

1. 德布羅意假說

1924 年德布羅意提出電子具有波動性，形成沿軌道的物質波。波長 λ = h/p，其中 p 為動量。

2. 駐波條件

$$ 2\pi r_n = n\lambda \quad (n = 1, 2, 3, \ldots) $$

圓周長必須容納整數個波長，首尾同相，形成穩定駐波。非整數 n 時首尾反相或錯相，波相互消。

因此電子軌道半徑 rn 只能取特定離散值，不能任意連續。

角動量量子化

代入 λ = h/p 並用 L = mvr = pr，得 L = nh/(2π) = nℏ。只有特定 n 的軌道穩定。

DSE 重點

展平波形可數出 n 個波長；比較 n = 3 與 n = 3.5，理解為何後者不能形成穩定原子軌道。

觀察步驟

1

觀察環形軌道上的青色物質波；整數 n 時波幅穩定，電子（黃點）沿軌道運動。

2

拖曳 n 滑桿或選預設；整數 n 為綠色「穩定駐波」，非整數為紅色「破壞性干涉」。

3

開啟「展平圓周」，把環形拉直成 2πr 直線，數出 n 個波長 λ 的分界線。

4

切換 n = 3.5，展平後觀察首尾波形高度不一致（Δ 標示），理解軌道無法閉合。

5

對照左側 L/ℏ 讀數與公式 L = nℏ；按「重置」回到 n = 3。
