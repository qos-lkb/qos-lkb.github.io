諧波與泛音公式

諧波 Harmonics（整數倍，含基音）

$$v=\sqrt{\frac{T}{\mu}},\quad f_1=\frac{v}{2L},\quad f_n=n f_1=\frac{n}{2L}\sqrt{\frac{T}{\mu}},\quad \lambda_n=\frac{2L}{n}$$

兩端固定：n = 1, 2, 3, …。波腹數 = n。

泛音 Overtones（基音以上的諧波）

$$k=n-1\quad(n\ge 2),\qquad f_k^{\mathrm{ot}}=(k+1)\,f_1$$

n = 1 是基音，不是泛音。第一泛音 k = 1 即第二諧波，頻率 2f₁。

一端自由（奇數諧波；弦樂器少見，用來對照氣柱）

$$f_n=(2n-1)\frac{v}{4L},\quad \lambda_n=\frac{4L}{2n-1}$$

原理解說

概念、機制與應用

1. 兩端固定的駐波

吉他、小提琴、鋼琴的弦兩端都是波節。相向行進波疊加後，只有整數個半波長能放進弦長 L。

$$f_n=n f_1=\frac{n}{2L}\sqrt{T/\mu}$$

2. 諧波與泛音不是同一編號

諧波從基音數起：第 1 諧波 = 基音。泛音從基音之上數起：第 k 泛音 = 第 (k+1) 諧波，所以 k = n − 1，頻率 (k+1)f₁。音色取決於各泛音的振幅比例。

3. 怎麼調音

拉緊弦（T 上升）或縮短有效弦長（按品）都會升高 f。較粗的弦 μ 較大，同樣張力下音較低。輕觸波節可孤立較高諧波（泛音奏法）。

觀察步驟

1. 選「吉他」預設，確認 n = 1 時只有一個波腹，讀 f₁。
2. 改 n = 2、3。核對 fₙ = n f₁，以及泛音序 k = n − 1。
3. 加大張力 T、再縮短 L，看頻率如何上升。
4. 切到「一端自由」，確認只剩奇數倍，λ 公式改為 4L/(2n−1)。
5. 按「聽此頻率」，比較基音與第一泛音（相差八度，頻率加倍）。
