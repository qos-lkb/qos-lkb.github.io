聲音多普勒效應物理原理與公式體系

一、通用多普勒效應總公式 (General Formula)

當聲源與探測器（觀察者）在同一直線上運動時，探測器接收到的表觀頻率 $f'$ 與聲源發射頻率 $f_0$ 之關係為：

$$f' = f_0 \left( \frac{v \pm v_o}{v \mp v_s} \right)$$
分子項 $(v \pm v_o)$（探測器效應）： 探測器靠近聲源取 $+$，遠離取 $-$。
分母項 $(v \mp v_s)$（聲源效應）： 聲源靠近探測器取 $-$，遠離取 $+$。
1 正在移動的聲源 ($v_s \neq 0, v_o = 0$)

當聲源移動時，聲波在介質中的傳播速度 $v$ 不變，但波前在移動方向上被「壓縮」，導致波長改變。

• 視波長：$\lambda' = \frac{v \mp v_s}{f_0}$
• 靠近時 ($v_s \to O$)：$f' = f_0 \left(\frac{v}{v - v_s}\right) > f_0$
• 遠離時 ($v_s \leftarrow O$)：$f' = f_0 \left(\frac{v}{v + v_s}\right) < f_0$

物理本質： 波長發生真實變短/變長（介質空間中的波前擠壓）。

2 正在移動的探測器 ($v_s = 0, v_o \neq 0$)

當探測器移動時，介質中的波長 $\lambda_0$ 保持不變，但探測器相對於聲波波前的「相對截獲速度」改變。

• 相對聲速：$v_{rel} = v \pm v_o$
• 靠近時 ($O \to S$)：$f' = f_0 \left(\frac{v + v_o}{v}\right) > f_0$
• 遠離時 ($O \leftarrow S$)：$f' = f_0 \left(\frac{v - v_o}{v}\right) < f_0$

物理本質： 空間波長未變，但單位時間內探測器穿過的波前數量改變。

3 聲源及探測器均在移動 ($v_s \neq 0, v_o \neq 0$)

同時疊加了「空間波長被聲源壓縮」與「探測器相對截獲速度改變」兩種效應。

• 雙方相向靠近：$f' = f_0 \left(\frac{v + v_o}{v - v_s}\right)$
• 雙方相離遠離：$f' = f_0 \left(\frac{v - v_o}{v + v_s}\right)$
• 同向追趕 ($S \to O$)：$f' = f_0 \left(\frac{v - v_o}{v - v_s}\right)$

特別注意： 若 $v_s = v_o$ 且同向移動（相對靜止），則 $f' = f_0$。

🚀 延伸觀念：超音速聲障與馬赫錐 (Mach Cone)

當聲源運動速度超過介質音速 ($v_s > v$) 時，分母 $(v - v_s)$ 變為負數，傳統多普勒公式不再直接適用於聲源正前方。此時所有先前發出的聲波圓環重疊重疊在一個圓錐形包絡面上，形成高能量的重疊波前——即震波 (Shock Wave / Sonic Boom)。

馬赫錐半頂角 (Mach Angle)： $\sin \theta = \frac{v}{v_s} = \frac{1}{M_s}$ (其中 $M_s$ 為聲源馬赫數)。

原理解說

Principle

1. 多普勒

波源與觀察者相對運動改變測得頻率。

2. 公式

$f'=f\frac{v\pm v_o}{v\mp v_s}$；近則波前壓縮。

3. 應用

救護車警號、雷達測速、超聲波測血流、宇宙學紅移。

觀察步驟

1. 觀察者預設在畫面正中；調整聲源或觀察者速度。
2. 按「播放探測音」，聽觀察者即時接收到的頻率。
3. 靠近時音調升高，讀數 \(f'\) 大於 \(f_0\)。
4. 交會後遠離，音調下降。
5. 對照公式，並試超音速預設看馬赫錐。
