等效電阻 物理

載入範例：

等效電阻 (Req)

0.00 Ω
系統狀態 計算成功
電阻器總數 0

基礎計算公式

串聯 (Series)
Req = R1 + R2 + ... + Rn
並聯 (Parallel)
1/Req = 1/R1 + 1/R2 + ...
*若任一並聯電阻為0，則整體等效電阻為0 (短路)。
模型操作指南 請把電路想像成「容器」。串聯容器內的電阻會相加；並聯容器內的電阻會倒數相加。你可以在容器內再加入容器或單一電阻，組合出多層電路。

觀察步驟

  1. 載入「基礎串並聯」，看右欄電路樹與左欄等效電阻。
  2. 改某個電阻的數值，確認串聯相加、並聯用倒數和。
  3. 在區塊內再加入串聯或並聯容器，看嵌套如何由內而外化簡。
  4. 把一個並聯電阻設成 0，觀察整體變成短路。

原理解說

概念。任意由電阻組成的两端網路，都可以化成一個等效電阻 Req，使外電路看到的電流與電壓關係不變。

機制。串聯：Req = R1 + R2 + …。並聯：1/Req = 1/R1 + 1/R2 + …。嵌套電路由最內層容器先算出一個等效電阻，再往外層合併。並聯中若有一支為 0 Ω，整段短路。

生活例子。家用插座上的電器彼此並聯，多開一盞燈總電阻下降、總電流上升；聖誕燈串若是串聯，一顆燒斷整串不亮。
